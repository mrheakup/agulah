# Агуулах

КЭЙ ЭЙЧ ИНТЕРНЭШНЬЛ ХХК-ийн агуулахын удирдлагын програм — бараа, орлого/зарлага, акт, худалдан авалт, агуулах ↔ үйлдвэр шилжүүлэг. Windows дээр суудаг, интернэтгүй ажилладаг, шинэ хувилбар гарахад автоматаар шинэчлэгддэг.

## Суулгах
[Releases](https://github.com/mrheakup/agulah/releases/latest) хэсгээс `Agulah-Setup-x.y.z.exe`-г татаж ажиллуулна. Windows «Windows protected your PC» гэж анхааруулбал **More info → Run anyway** дарна (кодын гарын үсэггүй тул).

Өгөгдөл: `%APPDATA%\agulah\agulah\data.json` (+ `data.bak.json` нөөц). Шинэчлэл болон програм устгахад өгөгдөл хөндөгдөхгүй.

## Шинэ хувилбар гаргах
1. `agulah.html` (эсвэл бусад файл)-д өөрчлөлт оруулна.
2. `package.json`-ийн `version`-ийг нэмнэ (жишээ нь `1.3.0` → `1.3.1`).
3. Commit хийгээд `main` руу push хийнэ (tag хэрэггүй):
   ```
   git commit -am "v1.3.1: ..."
   git push origin main
   ```
   GitHub вэб дээр шууд засаж болно: `agulah.html`-ийг сольж, дараа нь `package.json`-ийн `version`-ийг нэмээд **Commit changes** дарна.
4. GitHub Actions (`.github/workflows/release.yml`) суулгагчийг ~5 минутад бүтээж, `v1.3.1` tag-тай Release үүсгэнэ. Хувилбар өөрчлөгдөөгүй бол юу ч хийхгүй.
5. Суусан програмууд нээгдэх бүрт (мөн 4 цаг тутам) шалгаж, далд татаад дээд талд «Одоо шинэчлэх» товч гаргана. Хаахад ч автоматаар суна.

Гараар шалгах: цэс **Програм → Шинэчлэл шалгах**, эсвэл **Ангилал тохиргоо → 🔄 Шинэчлэл шалгах**.

## Хөгжүүлэлт
- Туршиж ажиллуулах: `npm install` → `npm start`
- Суулгагч локал бүтээх: `npm run dist`
- `agulah.html`-ийг браузерт шууд нээж ч ажиллуулж болно (localStorage-д хадгална).
